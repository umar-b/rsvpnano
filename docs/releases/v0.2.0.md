# RSVP Nano v0.2.0 — umar-b build

A large feature and hardening release. Everything passes the 481-case native
suite and builds clean in CI; the new touch/display surfaces (dictionary
overlay, auto night, new footer mode) still deserve an on-device shakeout.

## Highlights

- **Send to reader**: paste a URL in the companion and the device fetches and
  converts the page into an Article on its next RSS check. Direct `.epub`
  links download straight into the book library.
- **RSS full text**: feeds that only ship summaries can now pull the whole
  article ("Full articles" toggle under Wi-Fi settings).
- **Offline dictionary**: long-press the star corner while paused to look up
  the current word. Needs `/dict/` files on the card — build them with
  `tools/build_dict.py` (WordNet recipe in the script).
- **Adaptive pacing**: two sentence rewinds inside a minute ease the speed
  10% (up to 30%); a few quiet minutes ease it back. Your set WPM never
  changes. Off by default, under Pacing settings.
- **Auto night mode**: the theme follows the clock (21:00–07:00); manual
  changes hold until the next day/night edge.
- **"Finish by 21:42"**: a new footer metric showing the wall-clock time
  you'll finish the chapter at the current pace.
- **Stats tab in the companion**: a 30-day reading heatmap plus a JSON export
  of the daily history.
- **OTA is now TLS-verified**: firmware checks and downloads validate GitHub
  against a pinned root bundle once the clock has synced.
- Battery "time remaining" estimator, per-book WPM cleanup on delete, and the
  companion no longer clobbers the pace footer setting on save.

## Under the hood

- CI runs the native suite and the device build on every push.
- Four new pure modules (EPUB conversion kernel, JSON codec, focus-timer
  sequencer, book-index builder) with suites; native coverage grew from 378
  to 481 cases.
- One HTTP fetch kernel (with streaming-to-SD support) behind RSS, OTA, and
  the new download paths.

## Assets

- `rsvp-nano.bin` is the full browser-flasher image for fresh installs.
- `rsvp-nano-ota.bin` is the app-only binary used by OTA updates.
